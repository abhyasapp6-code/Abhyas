# Abhyas Bulk Question PDF Format

Use one question block at a time.

QUESTION_ID: SSC-CGL-Q001
EXAM: SSC CGL
SUBJECT: Quantitative Aptitude
TOPIC: Percentage
DIFFICULTY: Easy
QUESTION: 20 is what percentage of 80?
OPTION_A: 15%
OPTION_B: 20%
OPTION_C: 25%
OPTION_D: 30%
ANSWER: C
EXPLANATION: 20/80 × 100 = 25%.

## Rules
- QUESTION_ID must be unique.
- Required labels: QUESTION_ID, EXAM, SUBJECT, QUESTION, OPTION_A, OPTION_B, OPTION_C, OPTION_D, ANSWER.
- ANSWER must be A, B, C or D.
- Keep exactly four options for a single-answer MCQ.
- Start every new question with QUESTION_ID.
- Do not add commentary between field labels.
- Prefer plain text and avoid decorative formatting.
- The uploader should reject incomplete records for review instead of guessing missing data.
