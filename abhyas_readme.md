# Abhyas

Government-exam preparation platform starter for SSC, Railway and other competitive exams.

This upload package is intentionally flat: every file is at the ZIP root so all files can be selected together on GitHub.

## Included
- User App starter UI
- Admin Portal starter UI
- Question Upload starter UI
- Three demo exams
- Bulk-question PDF format specification
- Architecture notes

## Important
This is an initial frontend/data scaffold. Production authentication, database, payments, secure admin authorization and real PDF parsing should be connected before deployment.
